## 9. Facts that cost time — do not rediscover

- The engine's replaced operators **must stay exported** on macOS; hiding them splits the process along the libc++
  boundary (build 41). Foreign frees are handled in `awsTutorial.cpp` by the malloc-zone check (~9 ns per delete).
- Every CPU wait on a Metal GPU fence is lost in Mac **Shipping** (occlusion queries, HZB staging readback, `-norhithread`
  did not help); culling stays off via `MacEngine.ini`. Next step if pursued: a Shipping build with
  `bUseLoggingInShipping` and `UE_LOG` in `FMetalCommandBufferFence` (`MetalUAV.cpp:714-750`).
- A windowed Mac frame is display-synced: wall-clock p95 reads 33 ms at every rung; score by max(GPU, CPU) (build 39).
- `FDisplayMetrics` on macOS puts the Dock height into `WorkArea.Top`; use AppKit (`MacDisplayInsets.mm`).
- A file in `Source/awsTutorial/Mac/` does not see the module root on the include path (`#include "../X.h"`); UBT skips
  platform-named folders on other platforms, so `.mm` there is safe for Windows.
- `GetProfileInt` is a Win32 macro (renamed `ProfileGetInt`).
- The unattended Mac launch hangs in the fullscreen transition unless the saved mode is Windowed (build 38 persists it).
- `screencapture -x` over ssh returns a stale frame; `sample <pid> 3 -mayDie` works even on Shipping.
- Packaged UE ignores `-ini:` cvar overrides; use `Saved/Config/<Platform>/Engine.ini [SystemSettings]`.
- Both Mac configurations share `~/Library/Application Support/Epic/awsTutorial/Saved` — a Development run pre-tunes
  Shipping and vice versa.
