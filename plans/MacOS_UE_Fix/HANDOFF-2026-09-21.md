## 4. Build and test procedure

**Windows (first, always):** copy `graphics-autotune/package_win_NN.bat` (derive from `package_win_42.bat` with the
build number bumped and the header comment updated) into the project root; run `cmd.exe /c "package_win_NN.bat stage"`
for C++-only changes (~1 min each config), `all` when content/config changed (cook ~10+ min). Output
`Packaged\NN-dev\Windows` and `Packaged\NN-shipping\Windows`; logs `%TEMP%\gfxNN_package_win_{cook,dev,ship}.log`
(look for `BUILD SUCCESSFUL`, `PACKAGE_EXIT=0`, `ALL_DONE`). Dev runtime log:
`Packaged\NN-dev\Windows\awsTutorial\Saved\Logs\awsTutorial.log`; Shipping saves and settings:
`%LOCALAPPDATA%\awsTutorial\Saved\` (`Config\Windows\GameUserSettings.ini`, `[GraphicsAutoTune]` section).

**Mac:** on the Air, `~/gfx_autotune/package_mac_gfx.sh <backup-folder-name> first|rebuild` (nohup; `first` parks the
current apps into `<project>/.backups/<name>/apps/`, `rebuild` assumes they are parked). It runs the engine-patch guard
first (`check_engine_patch.sh`, aborts with `ENGINE_PATCH_MISSING`), then the team cook+stage script
(`~/Downloads/ue541-team-package/package-awsTutorial-mac.sh`, master `team-package/`), then Shipping
(`package_mac_shipping.sh`). Log `/tmp/gfx_package_mac.out` (ends `ALL_DONE`; `DEV_EXIT`/`SHIP_EXIT` lines), plus
`/tmp/awsTutorial-cook.log`, `/tmp/awsTutorial-stage.log`, `/tmp/awsTutorial-stage-shipping.log`, and UBT logs in
`~/Library/Logs/Unreal Engine/LocalBuildLogs/` (the compile error, if any, is in `/tmp/gfx_package_mac.out` too).
Output `Packaged/Mac/awsTutorial.app` (Dev) and `Packaged/Mac-Shipping/awsTutorial-Mac-Shipping.app`. About 7 min for
both when the cook is warm. Copy to another Mac with `tar -C … -cf - app | ssh … tar -xf -`, then
`xattr -dr com.apple.quarantine`.

**Mac runtime logs and state (both Development and Shipping share them, both run `-installed`):**
`~/Library/Logs/awsTutorial/awsTutorial.log` (Development only — Shipping writes no log),
`~/Library/Application Support/Epic/awsTutorial/Saved/Config/Mac/GameUserSettings.ini` (`[GraphicsAutoTune]`: `ProfileAC`,
`ProfileBattery`, `Applied`, `MacWindow=`, `Trace1..3=` — the decision trace is how a Shipping run is read),
`Input.ini` beside it (rewritten on a clean quit on the Air). Engine crash folders would be in
`…/Saved/Crashes/`; macOS crash reports in `~/Library/Logs/DiagnosticReports/` (note: the engine's own SIGABRT handler
logs to awsTutorial.log and exits without a macOS report — check the log first).

**Unattended Mac test (Air):** `~/gfx_autotune/mac_runtime_test.sh <dev|ship> <label> <seconds> term` launches, waits,
sends SIGTERM (graceful) and prints the key lines; `stage_gat_ini.sh set key=val… | restore <file>` edits the
`[GraphicsAutoTune]` section for a scenario. Unattended launches never open the microphone (no login), so the voice path
needs a real session. Always confirm no `awsTutorial` process is alive before resetting the ini (an exiting instance
rewrites it).

**Backups:** `graphics-autotune/backup_step.sh <project> <label>` snapshots Source, the voice plugin, Config and
Build/Mac into `<project>/.backups/<label>-<stamp>/` (portable WSL/macOS). Today's: `pre-linker-unexport-20260921T1527*`,
`pre-zone-free-20260921T1601*` (both projects); plans masters in `plans/MacOS_UE_Fix/.backups/pre-linker-unexport-…`.
Parked Mac apps: `.backups/build40-apps-20260921/apps/` (40), `.backups/build41-apps-20260921/apps/` (41).

## 9. Facts that cost time — do not rediscover

- The engine's replaced operators **must stay exported** on macOS; hiding them splits the process along the libc++
  boundary (build 41). Foreign frees are handled in `awsTutorial.cpp` by the malloc-zone check (~9 ns per delete).
- Every CPU wait on a Metal GPU fence is lost in Mac **Shipping** (occlusion queries, HZB staging readback, `-norhithread`
  did not help); culling stays off via `MacEngine.ini`. Next step if pursued: a Shipping build with
  `bUseLoggingInShipping` and `UE_LOG` in `FMetalCommandBufferFence` (`MetalUAV.cpp:714-750`).
- A windowed Mac frame is display-synced: wall-clock p95 reads 33 ms at every rung; score by max(GPU, CPU) (build 39).
- `FDisplayMetrics` on macOS puts the Dock height into `WorkArea.Top`; use AppKit (`MacDisplayInsets.mm`).
- A file in `Source/awsTutorial/Mac/` does not see the module root on the include path (`#include "../X.h"`); UBT skips
  platform-named folders on other platforms, so `.mm` there is safe for Windows.
- `GetProfileInt` is a Win32 macro (renamed `ProfileGetInt`).
- The unattended Mac launch hangs in the fullscreen transition unless the saved mode is Windowed (build 38 persists it).
- `screencapture -x` over ssh returns a stale frame; `sample <pid> 3 -mayDie` works even on Shipping.
- Packaged UE ignores `-ini:` cvar overrides; use `Saved/Config/<Platform>/Engine.ini [SystemSettings]`.
- Both Mac configurations share `~/Library/Application Support/Epic/awsTutorial/Saved` — a Development run pre-tunes
  Shipping and vice versa.
