# Gold-Set Drift Log

Running log of convention-validation findings. Populated at the item-25 convention-validation checkpoint and at every subsequent every-25-items drift check.

One entry per checkpoint. Entries record: date, checkpoint type, findings (including "no drift found" as a valid entry), and any actions taken or deferred.

Format:

```
## YYYY-MM-DD — <item-N checkpoint | every-25 drift check>

- Finding: <description; link to file:line if possible>
- Action: <in-place correction | parking-lot escalation | CONVENTIONS edit | none>
- Pattern watch: <note if this is the Nth recurrence of a prior finding>
```

See `CONVENTIONS.md` §8 for checkpoint procedures.
