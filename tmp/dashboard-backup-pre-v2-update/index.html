                    Style & Format

                    Writing Style
                    --style
                    Controls the overall tone and register of the generated text. 'Academic' uses formal language with hedging and citations. 'Professional' is clear and direct. 'Casual' is conversational. 'Technical' prioritizes precision and specificity.
                    Default: academic
                    Impact: Fundamentally changes vocabulary, sentence structure, and citation behavior.
                    Output Format
                    --format
                    Determines the structural format of the generated output. 'Paper' includes abstract, sections, and bibliography. 'Essay' is continuous prose. 'Report' includes executive summary and recommendations. 'Article' is for journal-style publication. 'Section' generates a single dissertation section with thesis-driven argumentation.
                    Default: paper
                    Impact: Changes document structure, headings, and overall organization.
                    Content Length
                    --length
                    Sets the target word count for generation. Longer outputs include more detail, examples, and supporting arguments. Short is best for summaries; comprehensive for full chapter sections.
                    Default: comprehensive
                    Impact: Directly affects generation time and token cost. Comprehensive can take 3-5x longer than short.

                    Corpus Integration

                    Use Corpus
                    --use-corpus
                    Enable corpus-aware content generation. When enabled, the writing pipeline retrieves relevant chunks from your ingested corpus and grounds the generated content in actual sources. This reduces hallucinations and improves citation accuracy.
                    Default: Off
                    Impact: Adds 10-30s to generation time. Significantly improves citation quality and factual grounding.
                    Collections /
                    Corpus Collections
                    --corpus-collections
                    Target specific collections within your corpus. If empty, all collections are searched. Use this to focus retrieval on relevant document groups (e.g., 'metaphysics', 'rhetorical_ontology').
                    Default: All collections
                    Impact: Narrower selection improves relevance but may miss cross-domain connections.
                    Loading collections...
                    Selected: 0 docs, 0 chunks
                    Corpus Chunks
                    --corpus-chunks
                    Number of corpus chunks to retrieve for context. More chunks provide broader grounding but increase input token cost. Optimal range is 10-25 for most tasks.
                    Default: 15
                    Impact: Each chunk adds ~500 tokens to input. 25+ chunks may hit context limits.
                    Relevance Threshold
                    --corpus-relevance
                    Minimum similarity score (0.0-1.0) for retrieved corpus chunks. Higher values return fewer but more relevant chunks. Lower values cast a wider net but may include tangential content.
                    Default: 0.75
                    Impact: Below 0.5 introduces noise. Above 0.9 may return too few chunks.

                    Source Verification

                    Verify Sources
                    --verify-sources
                    After generation, checks that every cited source exists in your ingested corpus. Reports verified vs. missing citations with detailed breakdowns. Essential for academic writing integrity.
                    Default: Off
                    Impact: Adds 5-15s post-generation verification pass.
                    Acquire Missing Sources
                    --acquire-missing
                    Automatically attempts to download open-access versions of missing cited sources. Uses Semantic Scholar and other repositories. Only downloads freely available papers.
                    Default: Off
                    Impact: May add 10-60s depending on number of missing sources and network speed.
                    Download Directory
                    --download-dir
                    Directory where automatically acquired sources are saved. Downloads are organized by author and year. Existing files are not re-downloaded.
                    Default: ./corpus/downloads
                    Impact: Ensure the directory exists and is writable.

                    Validation & Claim Enforcement

                    Inline Validator (Phase 11)
                    --use-inline-validation
                    Validates each paragraph DURING generation before appending it to the output. Prevents hallucinations at the source by checking citations, quote fidelity, and claim grounding in real-time. Paragraphs that fail validation are regenerated up to N retries.
                    Default: Off (auto-enabled when corpus has 3+ chunks)
                    Impact: Dramatically reduces hallucinations. Increases generation time 2-4x due to per-paragraph validation gates.
                    Inline Validation Strictness
                    --inline-validation-strictness
                    Controls how aggressively the inline validator rejects paragraphs. 'Strict' requires 100% citation pass rate. 'Moderate' allows minor issues. 'Lenient' only blocks serious hallucinations.
                    Default: moderate
                    Impact: Strict mode may cause excessive retries. Lenient may allow some unsupported claims through.
                    Max Retries per Paragraph
                    --inline-max-retries
                    Maximum regeneration attempts when a paragraph fails inline validation. After exhausting retries, the best-scoring attempt is used with a warning.
                    Default: 3
                    Impact: Higher values improve quality but increase generation time linearly.
                    Citation Lookup Tool-Use
                    --inline-enable-citation-lookup
                    Allows the LLM to call a citation_lookup tool during generation to find and verify citations against the corpus in real-time. The model can search for sources before citing them.
                    Default: On
                    Impact: Adds ~2-5s per paragraph but enables self-correcting citation behavior.
                    Citation Enforcement Mode
                    --citation-enforcement-mode
                    How to handle citation violations post-generation. 'Auto-correct' attempts to fix hallucinated citations. 'Strict' fails the generation if hallucinations exceed the threshold. 'Warn' flags issues but keeps the output.
                    Default: auto-correct
                    Impact: Strict mode may reject otherwise good content. Auto-correct adds a post-processing pass.
                    Minimum Citation Pass Rate
                    --citation-min-pass-rate
                    Minimum percentage of citations that must be verified against the corpus. Below this threshold, the citation enforcement mode is triggered (auto-correct, strict fail, or warn).
                    Default: 0.85 (85%)
                    Impact: Higher values demand more rigorous citation grounding. 0.95+ is very strict.
                    Maximum Hallucinations Allowed
                    --citation-max-hallucinations
                    Maximum number of hallucinated (unverifiable) citations allowed before triggering enforcement. Setting to 0 means zero tolerance for fabricated sources.
                    Default: 3
                    Impact: Lower values enforce stricter citation integrity. 0 is recommended for final dissertation output.
                    Endnote Generation
                    --enable-endnotes
                    Generates endnotes with supporting quotations from the corpus for each citation. Each endnote includes up to 3 verbatim quotations from the source material to evidence the claim.
                    Default: Off
                    Impact: Adds significant length. Requires corpus to be enabled. Essential for academic rigor.

                    Advanced

                    Staged Composition
                    --use-staged-composition
                    Enables the micro-meso-macro composition pipeline. First generates atomic claims (micro), then assembles paragraphs (meso), then composes full sections (macro). Produces more coherent and well-structured output.
                    Default: Off
                    Impact: Doubles generation time but significantly improves argument structure and flow.
                    Chapter Outline
                    --chapter-outline
                    Provide a structured JSON outline with thesis statement and section breakdown. The generator will follow this structure precisely. Useful for dissertation chapters with specific organizational requirements.
                    Default: null (auto-structured)
                    Impact: Provides strict structural guidance. Invalid JSON will fall back to auto-structuring.
