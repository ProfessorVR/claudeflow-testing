## 4. The matrix / formula — design sketch (built in Session 4)

Unit of analysis = a **chain-pass** (one perception→action actualization) or a bounded set. The phenomenon is read **once**, through the chain as spine.

**Layer 0 — Scope & frame.** Circumference (Burke); scale (discrete/protracted/ontological); entry point A₀-sense / A₂-imagination / A₃-thought (*De Motu Animalium*); register synchronic/diachronic; name the *orekton* (unmoved originator) driving the pass.

**Layer 1 — Chain spine (rows).** A₀ · M₀→A₁ · A₁ · M₁→A₂ · A₂ · M₂→A₃ · A₃ · M₃→A₄ · A₄ · [recursive A₄→A₀′ / hexis sedimentation]. Each motion row carries the three-factor schema (unmoved originator / moved mover / moved).

**Layer 2 — Two instruments per node (the binding).** At each node/motion: **(Calleja)** active dimension(s) + intensity + macro/micro + internalization trajectory = structural read; **(Burke)** featured pentad term(s) + operative ratio + identification state = motive read; bound by the validated crosswalk (Scene↔Spatial↔A₀; Agency↔Kinesthetic↔A₁-fluency/*technē*-hexis; Agent↔Shared↔A₃-collective; Attitude↔Affective↔A₁-valence/A₃-civic-passion; etc.).

**Layer 3 — Keystone (read across).** Incorporation R1–R5 ↔ consubstantiation, mapped to chain loci; verdict: incorporation met/partial/none/**ruptured**; consubstantiation genuine/strategic/**ruptured**. The A₃→A₄ "one substrate, two in being" substantial union.

**Layer 4 — Terminal diagnosis at A₄.** Action-type (1 Epithymetic / 2 Thymotic / 3 Bouletic / 4 Prohairetic, predominant source-desire); hexis-mode (*technē* / ethical); **7-causes attribution** (chance/nature/**compulsion-*bia***/habit/reasoning/anger/appetite — esp. agent-caused vs not); doxa state (ratified content + evaluative complexity).

**Layer 5 — Diachronic/recursive (protracted + ontological scales).** Which hexis sediments (*technē* vs ethical); which Stimmung saturates the next A₀; which doxai join the settled band; pathetic-loop effects (tone @ M₀→A₁; figure @ M₁→A₂; gate @ A₂→A₃); **(ontological scale)** the virtual→actual carry-over + the **supplanting-of-dispositional-ground verdict**.

**Scale variants:**
- **Discrete:** Layers 0–4, single circumference, synchronic.
- **Protracted:** a *sequence* of Layer 0–4 passes + heavy Layer 5; unit = the engineered hexis-bundle across passes; Calleja macro/micro load-bearing.
- **Ontological-change:** a single *rupture* pass (Layers 0–4 emphasizing *bia*, incorporation-rupture, phantasia-conscription, agent→patient inversion) + Layer 5 virtual→actual carry-over + supplanting verdict.

**The diagram (Session 4):** a visual of this layered matrix — chain spine vertical, two instruments as side-reads, keystone across, terminal diagnosis at A₄, diachronic loop wrapping back. "Like the interactive diagram in principle, not necessarily in form."
