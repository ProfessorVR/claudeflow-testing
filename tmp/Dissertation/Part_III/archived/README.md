## Convention

Documents chain `-v1-`, `-v2-`, `-v3-`… and prior versions are never edited. When a version is
superseded, a banner goes on the top of the file and it moves here. That keeps the working
folder to one current file per role while every earlier state stays recoverable.

The **desktop section** handoffs and drafts in `Part_III/` belong to a different workstream
that is separately active. They are untouched.
