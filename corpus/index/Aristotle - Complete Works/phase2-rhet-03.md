**One-sentence thesis**: Aristotle argues that persuasion depends not only on logical demonstration but equally on the speaker's character (ἦθος) and the hearer's emotional state (πάθη), and he systematically defines each major emotion -- anger, calm, friendship, enmity, fear, confidence, shame, kindness, pity, indignation, envy, and emulation -- by specifying three coordinates: the state of mind of the person feeling it, the persons toward whom it is directed, and the grounds on which it is felt.

## 2. Hierarchical Outline

```
Book II
├─ II.1  Transition: The Three Means of Persuasion in Combination
│   ├─ Recapitulation: materials for deliberative, epideictic, forensic oratory covered
│   ├─ Rhetoric exists to affect decisions (hearers as judges)
│   │   ├─ Orator must make his character (ἦθος) look right
│   │   └─ Orator must put hearers into the right frame of mind (πάθη)
│   ├─ Emotional states alter judgement
│   │   ├─ Friendly/placable → judge one way
│   │   └─ Angry/hostile → judge differently
│   ├─ Three sources of trust in speaker's character
│   │   1. Good sense (φρόνησις)
│   │   2. Excellence / virtue (ἀρετή)
│   │   3. Goodwill (εὔνοια)
│   └─ Programme: emotions to be treated under three heads each
│       ├─ (a) State of mind of those who feel the emotion
│       ├─ (b) Persons toward whom it is felt
│       └─ (c) Grounds on which it is felt
│
├─ II.2  Anger (ὀργή)
│   ├─ Definition: desire accompanied by pain for conspicuous revenge for slight
│   │   ├─ Slight must be undeserved
│   │   └─ Directed at particular individuals (not classes)
│   ├─ Pleasure attendant on anger (expectation of revenge)
│   │   └─ Homer: "Sweeter it is by far than the honeycomb" (Iliad XVIII.109)
│   ├─ Three kinds of slighting (ὀλιγωρία)
│   │   1. Contempt (καταφρόνησις)
│   │   2. Spite (ἐπηρεασμός)
│   │   3. Insolence (ὕβρις)
│   ├─ Persons toward whom anger is felt
│   │   ├─ Those who laugh, mock, jeer at us
│   │   ├─ Those who slight things we care about
│   │   ├─ Those from whom respect is expected (inferiors, friends, those obligated)
│   │   └─ Those who are indifferent to our suffering
│   └─ States of mind predisposing to anger
│       ├─ Sickness, poverty, love, thirst, unsatisfied desire
│       └─ Unexpected slights especially painful
│
├─ II.3  Calmness / Growing Calm (πραότης)
│   ├─ Definition: settling down or quieting of anger
│   ├─ Calm toward those who
│   │   ├─ Did not slight voluntarily / acted involuntarily
│   │   ├─ Admit fault and are sorry
│   │   ├─ Humble themselves before us
│   │   └─ Are serious when we are serious
│   ├─ Calm when we are not angry (amusement, laughter, feasting, prosperity)
│   ├─ Anger fades with time
│   ├─ Anger displaced by prior vengeance on another
│   │   └─ Example: Philocrates, Ergophilus, Callisthenes
│   └─ Rhetorical application: put hearers into calm frame of mind
│       └─ Represent adversaries as formidable, involuntary agents, or distressed
│
├─ II.4  Friendship and Enmity (φιλία / ἔχθρα)
│   ├─ Definition of friendly feeling: wishing good for someone for their sake
│   ├─ Friend = one who reciprocates this feeling
│   ├─ Conditions for friendship
│   │   ├─ Shared pleasure in same goods and evils
│   │   ├─ Same friends and enemies
│   │   ├─ Those who have treated us well
│   │   ├─ Those like ourselves in character and occupation
│   │   └─ Those who do not nurse grudges
│   ├─ Forms of friendship: comradeship, intimacy, kinship
│   ├─ Things that cause friendship: doing kindness unasked, without self-promotion
│   ├─ Enmity vs. anger
│   │   ├─ Anger = toward individuals; hatred = toward classes
│   │   ├─ Anger accompanied by pain; hatred not necessarily
│   │   ├─ Anger cured by time; hatred cannot be
│   │   └─ Angry man wants victim to feel pain; hater wants victim to cease to exist
│   └─ Rhetorical use: prove friendship/enmity to refute or support claims
│
├─ II.5  Fear (φόβος)
│   ├─ Definition: pain or disturbance from imagining destructive/painful evil in future
│   │   ├─ Not all evils feared -- only those near at hand
│   │   └─ Remote evils (death when young) not feared
│   ├─ Things feared: power to destroy/harm, injustice in possession of power
│   │   ├─ Enmity and anger of those with power
│   │   ├─ Outraged excellence in possession of power
│   │   └─ Those who have been wronged (seeking retaliation)
│   ├─ Persons feared
│   │   ├─ Rivals, those stronger than us
│   │   ├─ Those who have destroyed people stronger than us
│   │   └─ Quiet, dissembling, unscrupulous types (more than passionate/outspoken)
│   ├─ Conditions for feeling fear
│   │   ├─ Must believe something destructive can happen to us
│   │   ├─ Not felt by those in utter prosperity (insolent, contemptuous)
│   │   ├─ Not felt by those who have experienced every horror
│   │   └─ Must retain some faint expectation of escape
│   └─ Rhetorical application: make audience feel they are in danger
│       └─ Point to precedents of harm to people like them
│
├─ II.5 (cont.) Confidence (θάρσος)
│   ├─ Definition: opposite of fear; imaginative expectation of safety/absence of terrible
│   ├─ Conditions for confidence
│   │   ├─ Dangers remote, means of safety near
│   │   ├─ Have not wronged others / not been wronged
│   │   ├─ Rivals are friends or weaker
│   │   ├─ Believe ourselves stronger or equal
│   │   └─ Good relations with the gods (signs and oracles)
│   └─ Anger itself produces confidence
│
├─ II.6  Shame (αἰσχύνη) and Shamelessness (ἀναισχυντία)
│   ├─ Definition: pain or disturbance at bad things (past, present, future) bringing discredit
│   │   └─ Shamelessness = contempt or indifference regarding same
│   ├─ Things causing shame
│   │   ├─ Cowardice (throwing away shield, flight)
│   │   ├─ Injustice (withholding deposits)
│   │   ├─ Licentiousness (intercourse with forbidden persons)
│   │   ├─ Meanness (picking corpse's pocket, refusing to help)
│   │   ├─ Boastfulness, flattery, effeminacy
│   │   └─ Not sharing in honourable things shared by peers
│   ├─ Persons before whom we feel shame
│   │   ├─ Those who admire us or whom we admire
│   │   ├─ Rivals, those whose opinion we respect
│   │   ├─ Those likely to tell others about us
│   │   └─ Example: Cydias at Samos, Antiphon before Dionysius
│   ├─ Conditions for feeling shame
│   │   ├─ People related to those we feel shame before
│   │   ├─ Those who will witness our conduct
│   │   └─ More shame in public than in private
│   └─ "Shame dwells in the eyes" (proverb cited)
│
├─ II.7  Kindness (χάρις) and Unkindness
│   ├─ Definition: helpfulness toward someone in need, not for return or advantage
│   │   └─ Greatness of kindness: shown to one in great need, or rare/difficult help
│   ├─ Appetites as constituting need: desire, pain from non-attainment
│   │   └─ Sexual desire, bodily injury, danger
│   ├─ Those who help in poverty/banishment especially valued
│   │   └─ Example: man who gave mat in Lyceum
│   ├─ How to eliminate appearance of kindness (counter-argument)
│   │   ├─ Argue action was self-interested
│   │   ├─ Argue it was accidental or forced
│   │   └─ Argue it was mere return of favour
│   └─ Kindness particularized: specific magnitude, quality, time, place
│
├─ II.8  Pity (ἔλεος)
│   ├─ Definition: feeling of pain at apparent evil, destructive or painful, befalling one
│   │   who does not deserve it, and which we might expect to befall ourselves or kin
│   ├─ Condition: must believe evil can happen to us (not utterly ruined, not utterly prosperous)
│   ├─ Things exciting pity
│   │   ├─ Death, bodily injuries, old age, disease, lack of food
│   │   ├─ Friendlessness, scarcity of friends, deformity, weakness
│   │   ├─ Evil from unexpected source, repeated misfortune
│   │   └─ Good arriving too late (Great King's gifts to Diopeithes after death)
│   ├─ Persons pitied
│   │   ├─ Those we know (but not too closely -- too close = horror, not pity)
│   │   ├─ Those like us in age, character, standing, birth
│   │   └─ Example: Amasis wept at friend begging, not at son led to death
│   ├─ Proximity and vividness heighten pity
│   │   ├─ Gestures, tones, appearance, dramatic action
│   │   └─ Things just past or about to happen most piteous
│   └─ Signs of suffering: garments of the suffering, their words/actions
│
├─ II.9  Indignation (νέμεσις)
│   ├─ Definition: pain at undeserved good fortune (opposite of pity at undeserved bad fortune)
│   ├─ Both pity and indignation = marks of good character
│   ├─ Indignation vs. envy
│   │   ├─ Envy = pain at prosperity of equals/likes regardless of desert
│   │   ├─ Indignation = pain only at *undeserved* prosperity
│   │   └─ Two feelings cease: becomes fear if prospect of bad for ourselves
│   ├─ Things provoking indignation
│   │   ├─ Wealth, power, nobility acquired by the undeserving
│   │   ├─ Newly rich give more offence than old wealth
│   │   ├─ Inappropriate correspondence: fine weapons for merchants, not warriors
│   │   └─ Inferior contending with superior (musician vs. just man)
│   ├─ Persons who feel indignation
│   │   ├─ Those who deserve the greatest goods and have them
│   │   ├─ Those with sound judgement, loathing injustice
│   │   └─ The ambitious (when others get what they want undeservedly)
│   └─ Homer: Ajax / Zeus -- "when inferior contends with his superior"
│
├─ II.10  Envy (φθόνος)
│   ├─ Definition: pain at the sight of good fortune of equals, not for gain but because they have it
│   ├─ Persons who feel envy
│   │   ├─ Those with equals or near-equals in birth, age, disposition, wealth
│   │   ├─ The ambitious, small-minded
│   │   ├─ Those who profess wisdom (ambitious to be thought wise)
│   │   └─ Those who fall short of having everything
│   ├─ Persons envied
│   │   ├─ Those near us in time, place, age, reputation
│   │   ├─ Rivals, fellow-competitors
│   │   ├─ Neighbours and equals whose success reproaches us
│   │   └─ Those who have what we once had or nearly have
│   ├─ Things envied: honour, reputation, wealth, gifts of fortune
│   │   └─ Possessions that are reproach to us (our own fault we lack them)
│   ├─ Envy contrasted with emulation (φθόνος vs. ζῆλος)
│   │   └─ Envy = stop neighbour having; emulation = acquire for ourselves
│   └─ Aeschylus: "Ay, kin can even be jealous of their kin"
│
└─ II.11  Emulation (ζῆλος)
    ├─ Definition: pain at presence of valued goods in persons like us, not because they
    │   have them but because we do not
    │   ├─ Good feeling felt by good persons (vs. envy = bad feeling by bad persons)
    │   └─ Emulation → take steps to acquire; envy → stop neighbour having
    ├─ Persons who feel emulation
    │   ├─ Those who believe they deserve goods they lack
    │   ├─ The young, persons of lofty disposition
    │   ├─ Those whose ancestors/relatives/race were honoured
    │   └─ Those with goods already: courage, wisdom, public office
    ├─ Objects of emulation
    │   ├─ Courage, wisdom, public office, excellence
    │   ├─ Wealth and beauty (as serviceable/enjoyable)
    │   └─ All good things honoured by others
    ├─ Persons emulated
    │   ├─ Those already mentioned with these goods
    │   ├─ Generals, orators, those who can do many a good turn
    │   └─ Those praised, admired, eulogized by poets
    └─ Contempt as opposite of emulation
        └─ Those emulated by others are inevitably despised by some
```

## 8. Tensions

| Tension | Node A | Node B | Type | Description |
|---------|--------|--------|------|-------------|
| Emotion as irrational vs. emotion as structured judgement | πάθη as pain/pleasure (1378a20, PDF 46) | Three-headed rational analysis of each πάθος (1378a25, PDF 46) | Internal | Aristotle treats emotions as attended by pain/pleasure (suggesting affective, non-rational states) yet analyses each through cognitive components (beliefs about desert, persons, grounds), implying emotions have propositional structure |
| Anger at individuals vs. hatred at classes | ὀργή directed at particulars (1382a5, PDF 51) | ἔχθρα / μῖσος directed at types (1382a5, PDF 51) | Analytical | Strict individual/class distinction raises question of how rhetorical manipulation of anger toward a class (e.g., "all informers") works |
| Pity requires belief evil can befall us vs. pity for distant others | Self-referential condition (1385b15, PDF 57) | Pity for those unlike us (1386a20, PDF 58) | Internal | If pity requires imagining misfortune befalling oneself, how does one pity those radically unlike oneself? | Indignation as virtue vs. its proximity to envy | νέμεσις as mark of good character (1386b10, PDF 59) | φθόνος as closely related pain at others' fortune (1387b10, PDF 61) | Boundary | Aristotle insists on sharp distinction (desert-based vs. non-desert-based) but acknowledges they share phenomenological similarity and can transform into each other |
