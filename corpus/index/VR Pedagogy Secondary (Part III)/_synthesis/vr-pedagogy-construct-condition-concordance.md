# VR-Pedagogy Construct × Media-Condition Concordance

*medium.* Rows = the 14 canonical constructs; columns = the 8 canonical media-conditions. Each cell
lists the `ped-sec-NN` units whose data speaks to that construct under that condition (co-occurrence
of a `treats-construct` and a `tests-condition` edge in the same unit). Cells with no data are `—`.

primary deployment-era app-user stratum; `2D video/slideshow/text` = the video-only stratum.
