Actualization-of-Desire Analysis (ADA — provisional · v5 · Aristotelian-seated + dwelling-integrated) · how designed worlds actualize desire into rhetorical incorporation

An episode is a pass of the actualization of desire (A₀→A₄), driven by an orekton, that a designed world drives toward rhetorical incorporation — the two-faced substantial union (incorporation = world-face · consubstantiation = other-face) — diagnosed by whether the union sources the act, by cause → type → hexis, and by what it sediments / carries over.
