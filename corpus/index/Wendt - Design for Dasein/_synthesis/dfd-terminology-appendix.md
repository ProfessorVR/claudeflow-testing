# dfd — Terminology Appendix

Consolidated glossary of load-bearing terms across the indexed units, grouped by strand. Format: **term** — gloss — `(p.N / pdf N)` · unit. Anchor-phrases only; glosses paraphrase Wendt. (≥60 lemmas.)

## Phenomenology (classical / Heideggerian)
- **Dasein** — being-there / being-in-the-world; situated, embodied Being whose own being is an issue for it — (p.16 / pdf 18) · dfd-01
- **being-in-the-world ('in' as involvement)** — the "in" is absorption/involvement, not spatial containment — (p.16 / pdf 18) · dfd-01
- **ahead-of-itself / 'not yet'** — Dasein is future-directed (Stiegler's "having-to-be") — (p.18 / pdf 20) · dfd-01
- **thrownness (Geworfenheit)** — being dropped into a non-ideal world one must cope with — (p.18 / pdf 20) · dfd-01
- **coping** — dealing with the world by interacting with things; the default, representation-free mode (Dreyfus) — (p.18 / pdf 20) · dfd-01,05
- **ready-to-hand (Zuhandenheit)** — object as transparent means acted *through*; withdraws in use — (p.27 / pdf 29) · dfd-01,05
- **present-at-hand (Vorhandenheit)** — object observed as detached, analyzable thing; entered on breakdown — (p.26 / pdf 28) · dfd-01,05
- **withdrawal** — in absorbed use the equipment disappears from view — (p.28 / pdf 30) · dfd-01
- **absorbed coping** — action without conscious thought, caught up in the work (Dreyfus/Dourish) — (p.28 / pdf 30) · dfd-01,05
- **breakdown** — rupture of smooth coping; revelatory of "the tissue of relations" — (p.33 / pdf 35) · dfd-01,05
- **conspicuousness** — malfunctioning equipment becomes conspicuous, shifting to present-at-hand — (p.35 / pdf 37) · dfd-01
- **nearness (orientation, not proximity)** — an object is "near" insofar as it is part of one's current use-orientation — (p.45 / pdf 47) · dfd-01
- **care** — Dasein's concern for surrounding things; it finds its meaning in them — (p.44 / pdf 46) · dfd-01,06
- **equipmental whole** — the nearest things given as a unity, experienced "in excerpts" — (p.45 / pdf 47) · dfd-01
- **object vs thing (the jug)** — a self-supporting thing differs from an object; thingness "in the void that it holds" — (p.46 / pdf 48) · dfd-01,04
- **thing-ness / bringing-close (gathering)** — meaning-gathering carries us from object-ness to thing-ness — (p.46 / pdf 48) · dfd-01,04
- **physis** — natural form arising of itself, "form without intervention" — (p.37 / pdf 39) · dfd-01
- **technē** — making something appear through craft/the hands; the revealing intervention — (p.37 / pdf 39) · dfd-01,02
- **poiēsis** — bringing-forth; meaning emerging from a pre-existing state — (p.37 / pdf 39) · dfd-01
- **das Entbergen (bringing-forth)** — bringing forth what was safely hidden; concealment/unconcealment — (p.40 / pdf 42) · dfd-01
- **Herausfordern (challenging-forth)** — modern tech's revealing as a demand on nature; "de-worlds" materials — (p.40 / pdf 42) · dfd-01
- **standing reserve (Bestand)** — resource on call; renders the user passive — (p.41 / pdf 43) · dfd-01,05
- **enframing (Gestell)** — our relation to modern technology as gathered, stored, revealable energy — (p.43 / pdf 45) · dfd-01
- **The Turn (die Kehre)** — the shift from early (object) to late (essence-of-technology) Heidegger — (p.38 / pdf 40) · dfd-01
- **intentionality (Husserl)** — consciousness is always consciousness *of* something — (p.105 / pdf 107) · dfd-04
- **being-with (Mitsein)** — empathy is grounded in being-with, not its constituting bridge — (p.56 / pdf 58) · dfd-02

## Post-phenomenology, mediation & object studies
- **post-phenomenology** — Ihde's critique+continuation of phenomenology, redirected to everyday/individual devices — (p.84 / pdf 86) · dfd-04
- **mediation (constitutive)** — mediators help constitute what is real for us; not mere intermediaries — (p.96 / pdf 98) · dfd-04
- **technological intentionality / co-shaping** — technologies co-shape the human world (Verbeek) — (p.94 / pdf 96) · dfd-04
- **interrelational / mutually co-constitutive** — "I use the pen, but the pen uses me as well" — (p.86 / pdf 88) · dfd-04
- **embodiment relation** — object experienced *through*; it withdraws (eyeglasses, touch screen) — (p.87 / pdf 89) · dfd-04
- **hermeneutic relation** — object acted *with*, read/interpreted (thermometer, Twitter) — (p.88 / pdf 90) · dfd-04
- **background relation** — shapes experience without focal awareness (refrigerator) — (p.89 / pdf 91) · dfd-04
- **alterity relation** — technology as quasi-other / anthropomorphized (Siri) — (p.89 / pdf 91) · dfd-04
- **multistability** — technology "is what it does / what it can be," varying by context — (p.111 / pdf 113) · dfd-04,05,06
- **designer fallacy** — Ihde: the "deistic" notion of a designer-god whose artifact is intelligent by design — (p.104 / pdf 106) · dfd-04
- **intentional fallacy** — Wimsatt & Beardsley: judging a text by assumed authorial intent — (p.104 / pdf 106) · dfd-04
- **actant** — Latour: anything (human/non-human) that imposes intention in a system — (p.99 / pdf 101) · dfd-04
- **script / inscription** — an artifact's inscribed purpose (speed bump scripts slowing) — (p.100 / pdf 102) · dfd-04,05
- **delegation** — designers delegate responsibilities to artifacts — (p.100 / pdf 102) · dfd-04
- **for-ness** — Franssen: a technical artifact's purpose "clings" to it after the maker leaves — (p.106 / pdf 108) · dfd-04,05
- **schizofunctionality** — Baudrillard: an object's split functionality across a system of signs — (p.112 / pdf 114) · dfd-04
- **creative misuse** — using affordances beyond the script; reveals undiscovered needs — (p.107 / pdf 109) · dfd-04,05
- **context ('with text')** — peripheral information used to interpret a situation; forces systems thinking — (p.95 / pdf 97) · dfd-04
- **thing / thinging / gathering** — "the jug is a thing insofar as it things"; gathering of meaning — (p.118 / pdf 120) · dfd-04
- **the jug's void** — "the void is what does the vessel's holding"; the immaterial shapes the designed — (p.119 / pdf 121) · dfd-04
- **thing theory** — Bill Brown: "we look through objects but only catch a glimpse of things" — (p.120 / pdf 122) · dfd-04
- **matters-of-fact → matters-of-concern** — Latour: objects become things "rendered into objects of design" — (p.120 / pdf 122) · dfd-04
- **amplification / reduction** — Ihde: technologies that enable also obscure (the telescope) — (p.127 / pdf 129) · dfd-05
- **structural coupling** — Bonsiepe: design attaches artifacts to the body (phone as brain-extension) — (p.127 / pdf 129) · dfd-05
- **extended mind** — mind's function extends into the world (drives, phones, maps) — (p.126 / pdf 128) · dfd-05
- **object studies** — the cluster (post-phenomenology, OOO, ANT, thing theory) recentering objects — (p.90 / pdf 92) · dfd-04

## Embodiment & meaning-formation
- **embodied cognition** — thinking is embodied in the world; we interact and learn, not model-then-act — (p.124 / pdf 126) · dfd-05
- **body as ambiguous third party** — Merleau-Ponty: neither subject nor object; perception comes through it — (p.125 / pdf 127) · dfd-05
- **solicitations of situations** — skills stored as world-solicitations, not representations — (p.126 / pdf 128) · dfd-05
- **system of possible actions** — "my body is wherever there is something to be done" — (p.126 / pdf 128) · dfd-05
- **affordance** — Gibson: perceived action-possibility; "both physical and psychical, yet neither" — (p.130 / pdf 132) · dfd-05
- **unsemiotic affordance / forced abductive thinking** — Tonkinwise: a "promised action opportunity" between things and body — (p.132 / pdf 134) · dfd-05
- **embodied meaning** — meaning "arises from engaging and acting within the world"; a brain-in-a-vat has none — (p.133 / pdf 135) · dfd-05
- **product semantics** — Krippendorff: how designed objects participate in human affairs / support understanding — (p.135 / pdf 137) · dfd-05
- **sense vs meaning** — sense = one context; meaning = sum of all imaginable contexts — (p.137 / pdf 139) · dfd-05
- **design as declarative act** — design produces a reality rather than describing one — (p.139 / pdf 141) · dfd-05
- **interface** — the point of sensemaking & structural coupling; a "generative friction," not a passive link — (p.140 / pdf 142) · dfd-05
- **interface as active mediation (third entity)** — Hookway: holds-apart + draws-together → an emergent user-system — (p.143 / pdf 145) · dfd-05
- **transparency vs invisibility** — perceived-through and re-enterable (transparent) vs needing an aid (invisible) — (p.146 / pdf 148) · dfd-05
- **transparency of use vs of context** — perceptual neutrality vs awareness of the mediating role — (p.147 / pdf 149) · dfd-05
- **double desire / paradox of invisibility** — Ihde: wanting both total transparency and the power technology gives — (p.148 / pdf 150) · dfd-05
- **semantic turn** — Krippendorff: from humans-adapting-to-tech toward meaning and "feeling at home" — (p.149 / pdf 151) · dfd-05
- **systemic turn** — extension toward service/speculative design and systemic thinking — (p.150 / pdf 152) · dfd-05
- **situated design** — Brereton: understanding/constructing the situation is core; context is enacted — (p.151 / pdf 153) · dfd-05
- **embodied interaction** — Dourish: embodiment as constitutive of the whole interaction phenomenon — (p.152 / pdf 154) · dfd-05
