# dfd… — Terminology Appendix (RDR2 cluster)

Load-bearing game-studies / rhetoric / theory terms used across the cluster, grouped by strand. Format: **term** — gloss — units. (≥50 lemmas.)

## Rhetoric / ludonarrative / procedure
- **procedural rhetoric** — Bogost: persuasion through rules/systems, not (only) words/images — rdr-01, rdr-08, rdr-03
- **honor system / honor gauge** — the morality meter read as the game's argumentative/ideological/affective spine — rdr-01–04, rdr-07–09
- **ludo-narrative porosity** — mechanics and fiction co-produce meaning (Barnabé/Hurel); refuses ludology-vs-narratology — rdr-01
- **mechanics-vs-fiction (locus of meaning)** — where meaning resides (systems vs story) — rdr-01, rdr-08, rdr-03
- **play as "free space of movement within a rigid structure"** — Salen & Zimmerman (via Bogost) — rdr-08
- **reader-response theory** — Rosenblatt/Fish: the game "read" like a text by an active reader — rdr-08
- **avatar-marionnette** — the avatar as the player's manipulated stand-in — rdr-01
- **the Other** — represented racial/ethnic/gendered outsider (Native, Mexican, immigrant, African American) — rdr-08, rdr-01, rdr-05
- **completionist vs experiential player** — two play stances toward content — rdr-08

## Ideology critique
- **Ideological State Apparatus (ISA) / Repressive State Apparatus (RSA)** — Althusser; located in culture AND inside the diegesis — rdr-03, rdr-01
- **interpellation / hailing** — the game "hails" the player; progression = ideological absorption — rdr-03
- **directed / illusory freedom** — open-world choice as "every choice already made" — rdr-03, rdr-10
- **field of possibilities / incomplete universe** — what is rendered possible vs impossible encodes a worldview — rdr-03
- **series-as-canon** — ideology legible only across RDR2+RDR read as one — rdr-03
- **Spaghetti-Western / RSA-plot** — the radical Italian Western as anti-capitalist critique transplanted to AAA — rdr-03
- **the Rockstar contradiction** — progressive content vs exploitative (crunch) production — rdr-03, rdr-05
- **moral disengagement** — Hartmann & Vorderer; how games license player wrongdoing — rdr-05

- **material accuracy** — period objects, buildings, organisations, outfits — rdr-11

- **developer-historian / Rockstar's historiography** — Chapman: the studio as history-maker — rdr-05
- **digi-Whiggish / teleological game historiography** — progress-narrative history of games themselves — rdr-05
- **narratives of "progress"** — civilization/savagery progress across history, brand, and diegesis — rdr-05
- **the "F-word" (Frontier) / civilization–savagery binary** — the Western's ideological core — rdr-05, rdr-08, rdr-01, rdr-02
- **playing Indian** (Deloria); **the vanishing American** (Dippie); **safety-valve / yeoman myth** — frontier ideologemes — rdr-05
- **games as text / inquiry pedagogy** — games read as historical text; classroom inquiry-gateway — rdr-11, rdr-08
- **deep play / historical imaginary** — Denning; immersive historical feeling — rdr-08
