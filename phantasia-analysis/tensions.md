## Tensions

### Tension 1: Phantasia as Appearance vs as Faculty

| Field | Value |
|-------|-------|
| Poles | Phenomenal seeming (appearance) / Cognitive capacity (faculty) |
| Description | Aristotle distinguishes phantasia-as-appearing (*phainesthai*) from phantasia-as-faculty (*he phantasia*). The chapters need both senses: phantasia AS A FACULTY produces APPEARANCES that structure emotion and thought. |
| Key Units | U1, U4, U6 |
| Status | Partially resolved in Doc B ("The Resolution": phantasia is BOTH). NOT explicitly resolved in Doc A. |
| Resolution Path | Import B's resolution into A: phantasia is the faculty that produces appearances, and those appearances are the mode in which the world shows up. |

### Tension 2: Phantasia vs Memory

| Field | Value |
|-------|-------|
| Poles | Phantasia stores traces / Memory stores traces |
| Description | Both retain past experience, but the chapter asserts they have "distinct temporal phases." Memory is past-directed; phantasia is temporally flexible. The mechanism of distinction is asserted but not fully argued. |
| Key Units | U5 |
| Status | Open. Doc C meta-note: "Make sure to clarify the difference between the storage capabilities of phantasia and memory proper." |
| Resolution Path | Develop the temporal directionality argument: memory can ONLY re-present what was; phantasia can present what was, what is, what might be, or what never was. |

### Tension 3: Phantasia vs Mood (as Disclosure)

| Field | Value |
|-------|-------|
| Poles | Phantasia discloses (through images) / Stimmung discloses (through attunement) |
| Description | Both are described as "world-disclosing." Can Stimmung subsume phantasia's disclosive function without losing the specific, imagistic character of phantastic disclosure? |
| Key Units | U8, U9, U10 |
| Status | Partially resolved: Stimmung discloses the HORIZON; phantasia discloses PARTICULAR CONTENT within that horizon. But U10's bidirectionality complicates this: if phantasia-generated emotions modify mood, phantasia indirectly shapes the horizon. |
| Resolution Path | Maintain the horizon/content distinction but acknowledge the bidirectional relationship. |

### Tension 4: Form-Reception vs Meaning-Constitution

| Field | Value |
|-------|-------|
| Poles | Aristotle: form received without matter (hylomorphism) / Heidegger: meaning constituted through attunement |
| Description | Aristotle's perceiver receives form; Heidegger's Dasein constitutes meaning. Are these compatible frameworks or do they answer fundamentally different questions? |
| Key Units | U7, U8 |
| Status | The chapter argues compatibility: mechanism (Aristotle) + significance (Heidegger) = complete account. But whether they are truly compatible or merely complementary is underdeveloped. |
| Resolution Path | Acknowledge that they answer different questions (how perception works / why it matters) and argue that both questions are necessary for a complete account of human experience. |

### Tension 6: Perception vs Judgment

| Field | Value |
|-------|-------|
| Poles | Aisthesis as purely receptive / Aisthesis as already discriminating |
| Description | The wax analogy suggests pure reception (form impressed on matter). But the dynamis→energeia transition implies the perceiver contributes. Doc C notes: "Aristotle doesn't seem to distinguish between aisthesis, direct sensation, and perception proper." |

### Tension 7: Error vs Universality

| Field | Value |
|-------|-------|
| Poles | Phantasia activated by cognitive failure / "Soul never thinks without phantasma" (DA III.7, 431a16-17) |
| Description | If phantasia only activates when perception fails (darkness, distance, rapid motion), it's a special-case faculty. But "the soul never thinks without a phantasma" makes it universal. |
| Key Units | U1 |
| Status | Resolved in Doc B ("The Resolution"): phantasia is universal (the soul always thinks with phantasmata); error cases are where phantasia becomes NOTICEABLE, not where it begins operating. |
| Resolution Path | Import B's resolution: phantasia is always operating; it becomes visible in error cases. |

### Tension 8: Pathos as Emotion vs as Affection

| Field | Value |
|-------|-------|
| Poles | Modern "emotion" (structured, intentional feeling) / Aristotle's "being-affected" (*paskhein*, broader) |
| Description | The etymology argument ("emotion = e-motion") bridges Greek and modern senses, but *pathos* is broader than "emotion" — it includes any being-affected, including sensation itself. |
| Key Units | U6 |
| Status | Open. The chapter uses "emotion" and "pathos" somewhat interchangeably; the Greek term is broader. |
| Resolution Path | Distinguish levels: *pathos* (broadest: any being-affected) > *pathema* (specific affective response) > emotion (modern: structured, intentional, phenomenologically rich). |

### Tension 9: Voluntary vs Involuntary Phantasia

| Field | Value |
|-------|-------|
| Poles | "Call up a picture at will" (DA III.3, 427b17-20) / "In forming opinions we are not free" |
| Description | Deliberative phantasia is voluntary (we can summon images); sensitive phantasia is involuntary (appearances compel us). This maps onto but doesn't exactly match the sensitive/deliberative distinction. |
| Key Units | U6 |
| Status | Open. The mapping to sensitive/deliberative is approximate. Some deliberative phantasia may be involuntary (unbidden memories of deliberative content). |
| Resolution Path | Clarify that the voluntary/involuntary axis and the sensitive/deliberative axis are related but orthogonal. |

### Tension 10: Resonant Motion vs Resonant Affect

| Field | Value |
|-------|-------|
| Poles | Kinetic trace (physical motion in sense organ) / Affective trace (subjective-affective coloration) |
| Description | The author distinguishes these as two dimensions of a single perceptual event. But: are they really separable? Can you have resonant motion without resonant affect? Is the distinction ontological or merely analytical? |
| Key Units | U9 |
| Status | Open. The distinction is asserted but not argued from text. |
| Resolution Path | Argue that they are analytically separable but ontologically inseparable — every perceptual kinesis carries both a formal trace and an affective trace. The distinction is a tool of analysis, not a claim about separate processes. |

### Tension 11: Subsumption vs Complementarity

| Field | Value |
|-------|-------|
| Poles | Mood SUBSUMES phantasia / Mood COMPLETES phantasia |
| Description | Ch 2 sec. 2.5 title: "How Mood Subsumes Phantasia." Ch 2 sec. 2.5 body: "ontological completion." Doc E: "Both as Conditions of Possibility" (parallel, symmetric). The question: does phantasia lose autonomy under Stimmung, or retain its own explanatory domain? |
| Key Units | U10 |
| Status | **Central unresolved tension**. The chapter uses "subsumption" language in the heading but "completion" language in the argument. |
| Resolution Path | The edge vocabulary uses `completes` (not `subsumes`). Recommend the author either (a) change the sec. 2.5 heading to "completion" or (b) explicitly argue that subsumption-as-completion preserves phantasia's autonomy within its domain. |

### Tension 12: Mechanistic vs Phenomenological

| Field | Value |
|-------|-------|
| Poles | Aristotle's causal/faculty account / Heidegger's existential/phenomenological account |
| Description | The chapter argues they are compatible: "Where Aristotle gives us a mechanistic, causal ontology... Heidegger gives us a phenomenological ontology." But are they really compatible, or do they answer incommensurable questions? |
| Key Units | U10 |
| Status | The chapter claims compatibility. The argument rests on the "mechanism + significance = complete account" formula. Whether this formula is philosophically defensible is the deepest question the chapter raises. |
| Resolution Path | Develop the argument that mechanism and significance are complementary descriptions of the same phenomenon at different levels of analysis — analogous to physical and chemical descriptions of the same process. |
